# Рекомендуемые моды и сборки

## Таблица модов

| Мод / Сборка | Назначение | Ресурсы |
|--------------|------------|---------|
| **ReHLDS + ReGameDLL_CS** | Современная замена оригинального HLDS, ARM-совместимость | Низкие |
| **Metamod-R + AMX Mod X** | Платформа для плагинов (админка, привилегии, ивенты) | Низкие |
| **ReDeathmatch** | Режим Deathmatch / Free-for-All | Средние |
| **YaPB / PodBot** | Боты для заполнения сервера | Низкие |
| **ReUnion** | Поддержка 47/48 протоколов и non-Steam клиентов | Низкие |
| **CSDM / AIM** | Тренировочные сборки | Низкие |
| **Zombie Plague** | Популярный мод на выживание | Средние |

## Готовая сборка для быстрого старта

**[red-magic/cs16-server](https://github.com/red-magic/cs16-server)** — установка в 1 команду.

```bash
git clone https://github.com/red-magic/cs16-server.git
cd cs16-server
docker-compose up -d
```

## Docker-образы

| Образ | Описание |
|-------|----------|
| `cajuclc/cstrike-docker` | ARM-совместимый CS 1.6 сервер |
| `cstrike-arm` | Сборка для ARM платформ |

## ARM-совместимые компоненты

- **ReHLDS** — компилируется под ARM
- **Metamod-R** — плагин для загрузки модов
- **AMX Mod X** — расширение для плагинов на Pawn
