# Telegram-бот @cs_economic_bot

## Основная цель

Бот **не дублирует MOTD** — он служит вспомогательным каналом:
- Уведомления о событиях в игре (атаки, захваты, прибыль)
- Конвертация Telegram Stars → Coins
- Просмотр баланса и статуса бизнесов
- Оповещения о клановых войнах

---

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие, привязка SteamID, главное меню |
| `/balance` | Баланс Coins и Stars |
| `/convert` | Конвертация Stars → Coins |
| `/business` | Список бизнесов с уровнем и доходом |
| `/clan` | Информация о клане |
| `/war` | Текущий статус войны |
| `/profile` | Статистика игрока |
| `/help` | Список всех команд |

## Техническая интеграция

Бот работает на **OPi #4** (или отдельном сервере) и взаимодействует с:
- **API OPi #3** — для получения данных о балансе, бизнесах, войне
- **MySQL** — для чтения/записи данных игроков
- **Telegram Stars Payments** — для обработки платежей
- **Ежедневный cron-скрипт** проверяет удержание редких городов и через бота начисляет Stars
