# Анализ рынка и可行性 (Feasibility)

## Техническая可行性

Запуск сервера CS 1.6 на Orange Pi Zero с 1GB RAM **технически возможен**, но с ограничениями:

| Компонент | Описание | Ограничение |
|-----------|----------|-------------|
| **Процессор** | ARM-архитектура (как у Raspberry Pi) | Нативный HLDS собран под x86 → требуется эмуляция (Box86 + Wine) или ARM-совместимые сборки (ReHLDS) |
| **ОЗУ** | 1 ГБ — минимальный порог | Рекомендуется **не более 8-12 слотов** для стабильной работы без лагов |
| **Хранилище** | Минимум 10 ГБ свободного места | - |

### Оптимальный путь
Docker-контейнер с ARM-сборкой (например, `cajuclc/cstrike-docker`) или сборка на основе **ReHLDS + Metamod-R**.

## Рыночная ситуация (2025-2026)

### Аудитория
- В основном **нелицензионные клиенты (non-Steam)**
- Популярные моды: CSDM / AIM, Zombie Plague, Jail Break, DeathRun, 35hp сервера

### Конкуренция
- **Тысячи серверов** — чтобы выделиться, нужна уникальная механика:
  - Токенизация
  - Рейтинговая система
  - Турниры

### Мониторинги
- Продвижение через игровые мониторинги (gamemonitor, cs-monitor)
- **Платно**, но необходимо для наполнения сервера
