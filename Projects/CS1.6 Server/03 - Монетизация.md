# Монетизация

## Методы монетизации

| Метод | Описание | Пример цен |
|-------|----------|------------|
| **VIP-привилегии** | Доступ к слоту, скины, доп. здоровье, деньги | 10-20 €/мес |
| **Админ-права** | Продажа флагов администратора | 50-100 €/мес |
| **Донат-меню** | Внутриигровые покупки (оружие, скины, эффекты) | 200-400 руб |
| **Токенизация** | Майнинг токенов за игру, обмен на VIP | Тестнет |
| **Турниры** | Вступительный взнос, призовой фонд | Договорная |
| **Реклама** | Баннеры на сайте / в мотивационных сообщениях | Договорная |

## Стратегия запуска

1. **На старте** — бесплатный VIP в прайм-тайм (как у XPlayZM) для привлечения игроков
2. **Затем** — платные пакеты

## VIP-система

| Уровень | Цена | Привилегии |
|---------|------|------------|
| Bronze | 500 руб/мес | Доп. здоровье,/colors |
| Silver | 1000 руб/мес | Скины, приоритет |
| Gold | 2000 руб/мес | Все привилегии + слот |
