# Промпт для ИИ-агента (OpenCode)

## Контекст

Ты — ИИ-агент, развернутый через OpenCode на сервере-аналоге Orange Pi Zero (1GB RAM, ARM-архитектура, Linux).

**Твоя задача** — автоматизировать полный цикл управления игровым сервером Counter-Strike 1.6.

---

## Техническое задание

### 1. Установка и настройка

- Установи Docker и Docker Compose
- Разверни ARM-совместимый CS 1.6 сервер (используй образ `cajuclc/cstrike-docker` или сборку ReHLDS + Metamod-R)
- Настрой проброс портов:
  - UDP 27015 (игровой)
  - TCP 27015 (RCON)
  - Порт для FastDL (опционально)
- Установи плагины:
  - AMX Mod X
  - ReDeathmatch (для Deathmatch-режима)
  - YaPB (боты)
  - ReUnion (non-Steam поддержка)

### 2. Автоматизация

- Скрипт для авто-запуска сервера при загрузке системы (systemd или crontab)
- Мониторинг ресурсов (CPU, RAM, онлайн) с отправкой алертов в Telegram/Discord при превышении 80% загрузки
- Автоматический бэкап конфигов и карт раз в сутки

### 3. Интеграция с сайтом

Настрой REST API (на базе Python/Node.js) для:
- Выдачи VIP/админ-прав по запросу с сайта
- Сбора статистики игроков (убийства, смерты, время игры) и отправки на сайт
- Управления сервером (старт/стоп/рестарт) через веб-интерфейс

Реализуй FastDL для автоматической скачивания карт и скинов клиентами.

### 4. Монетизация

- Внедри донат-меню через AMXX-плагин (покупка скинов, дополнительного здоровья, денег)
- Настрой систему VIP-слотов (приоритетное подключение при заполненном сервере)
- Интеграция с платежной системой (ЮKassa или криптовалюта) через веб-хуки

### 5. Безопасность

- Ограничь RCON-доступ по IP
- Веди лог всех админ-действий
- Настрой защиту от DDoS (iptables + rate limiting)

### 6. Тестирование и мониторинг

- Скрипт для проверки доступности сервера каждые 5 минут (при падении — авто-рестарт)
- Генерация отчета о работе сервера раз в неделю (онлайн, доходы, топ-игроки)

---

## Итоговый результат

Полностью автономный CS 1.6 сервер с веб-панелью управления, донатом и автоматическим восстановлением, работающий на Orange Pi Zero 1GB.
