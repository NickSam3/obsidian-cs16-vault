# Геймплейный цикл

## Микро-цикл (2–5 минут)

```
Спавн → Бой → Фраг/захват точки → Заработок Coins → Повтор
```

## Макро-цикл (10–30 минут)

```
Бой → Открытие !menu → Проверка баланса → Инвестиции/покупки → Возврат в бой
```

## Мета-цикл (ежедневно/еженедельно)

```
Забрать прибыль → Выполнить контракты → Улучшить бизнес → Выйти в топ → Повтор
```
