# Риски и их минимизация

| Риск | Решение |
|------|---------|
| **Инфляция Coins** | Лимит фарма в день, комиссия на бирже, сжигание при улучшениях |
| **Техническая нестабильность OPi** | Мониторинг, авто-рестарт, бэкапы, ограничение слотов |
| **Отсутствие онлайна** | Бесплатный VIP для первых 50 игроков, реклама у блогеров |
| **Дисбаланс кланов** | Динамическое преимущество слабому клану, коалиции |
| **Pay-to-win** | Бонусы скинов только косметические или минимальные |
| **Сложность для новичков** | Встроенный туториал в MOTD, стартовый капитал |
