# Связка с сайтом

## Компоненты интеграции

| Компонент | Решение |
|-----------|---------|
| **Панель управления** | GreyPanel V2 (API-мост для выдачи привилегий) |
| **API бэкенд** | ASP.NET Core 8 + JWT (управление серверами, ELO-рейтинг) |
| **Лаунчер** | Electron-приложение для входа, списка серверов, доната |
| **Статистика** | Плагин AMXX, отправляющий данные (убийства, время) на сайт |
| **Управление сервером** | API для ВКЛ/ВЫКЛ/РЕСТАРТ, смена пароля |
| **Быстрый вход** | `steam://connect/ip:port` |

## Минимальный вариант

- **WordPress** + плагин для доната
- **AMXX-плагин** для синхронизации данных

## REST API (Python/Node.js)

### Эндпоинты

| Метод | URL | Описание |
|-------|-----|----------|
| `POST` | `/api/vip/grant` | Выдача VIP/админ-прав |
| `GET` | `/api/stats/:steamid` | Статистика игрока |
| `POST` | `/api/server/start` | Запуск сервера |
| `POST` | `/api/server/stop` | Остановка сервера |
| `POST` | `/api/server/restart` | Перезапуск сервера |

### Пример запроса

```json
{
  "steam_id": "STEAM_0:1:12345678",
  "vip_level": "silver",
  "expires": "2026-12-31"
}
```

```

```
