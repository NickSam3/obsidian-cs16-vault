# Техническая архитектура

## Стартовая конфигурация (1× Orange Pi Zero 1GB)

| Параметр | Значение |
|----------|----------|
| **Устройство** | Orange Pi Zero 1GB |
| **IP** | 192.168.1.7 |
| **SSH** | root@20051996 |
| **ОС** | Armbian |
| **Роль** | ВСЁ В ОДНОМ: Игровой сервер + API + Веб + БД + Бот |

> **Важно:** На старте все сервисы работают на одной OPi. При расширении до 4 OPi — разделение ролей.

---

## Распределение ролей (расширенная конфигурация)

### Старт (1 OPi)

| Сервис | Порт | Контейнер |
|--------|------|-----------|
| CS 1.6 Server | 27015/udp, 27015/tcp | cs16 |
| API Backend | 5000/tcp | api |
| Веб-сервер (Nginx) | 80/tcp | nginx |
| Telegram-бот | — | bot |
| БД (SQLite) | — | файл .db |

### Расширение (4 OPi)

| Устройство | Роль | Нагрузка | Слоты |
|------------|------|----------|-------|
| **OPi #1** | Основной игровой сервер (ReHLDS) | Высокая | 16–20 (штурмы) |
| **OPi #2** | Второй игровой сервер (ReHLDS) | Средняя | 10–12 (скирмиши) |
| **OPi #3** | Стратегический сервер + API | Средняя | — |
| **OPi #4** | Веб-сервер + БД + FastDL + Telegram-бот | Низкая | — |

---

## Сетевая схема

### Старт (1 OPi)

```
(Интернет) → Роутер (порт 27015→192.168.1.7)
                    ↓
            OPi #1 (Всё-в-одном)
```

### Расширение (4 OPi)

```
(Интернет) → Роутер (порты 27015→OPi#1, 27016→OPi#2)
        ↓
OPi #1 (Игровой 1) ←→ OPi #3 (API) ←→ OPi #2 (Игровой 2)
                             ↑
                        OPi #4 (Веб + БД + Бот)
```

## Единый домен

**cs-economic.duckdns.org** — все сервисы на одном домене:

| Сервис | Доступ |
|--------|--------|
| Игровой сервер #1 | cs-economic.duckdns.org:27015 |
| Игровой сервер #2 | cs-economic.duckdns.org:27016 |
| MOTD (веб-интерфейс) | http://cs-economic.duckdns.org/menu.html |
| API | http://cs-economic.duckdns.org/api/ |
| FastDL | http://cs-economic.duckdns.org/fastdl/ |

> **Примечание:** DuckDNS — бесплатный DDNS, подходит для старта. Позже планируется переход на платный домен.

## Стек технологий

| Компонент | Технология | Примечание |
|-----------|-----------|------------|
| ОС | Armbian | Легковесная для ARM |
| Контейнеризация | Docker + Docker Compose | Изоляция сервисов |
| Игровой движок | ReHLDS + ReGameDLL_CS (ARM) | ARM-совместимая сборка |
| Платформа плагинов | Metamod-R + AMX Mod X | Для плагинов на Pawn |
| База данных | **SQLite** (старт) → **MySQL** (расширение) | SQLite не требует ресурсов |
| Веб-сервер | Nginx | Раздача статики + проксирование API |
| Backend API | Python (Flask) | Простой REST API |
| Telegram-бот | Python (aiogram) | Асинхронный бот |
| MOTD | HTML 4.01 / CSS 2.1 / **ES5** | **БЕЗ fetch() — только XMLHttpRequest** |

---

## Важные технические ограничения

### MOTD (Клиент CS 1.6)

| Параметр | Значение |
|----------|----------|
| Движок | Trident (IE) / WebView |
| JavaScript | **ES5** (нет const/let, нет arrow functions) |
| HTTP | **XMLHttpRequest** (fetch НЕ работает!) |
| CSS | CSS 2.1, частично CSS3 |
| Размер | 800×600 px |
| CORS | Запрещён |

### AMXX плагины

| Параметр | Значение |
|----------|----------|
| HTTP-запросы | **http2.amxx** или **netchan** (AmxxEasyHttp не подтверждён для ARM) |
| БД | SQLite через sqlx или MySQL через sqlx |
| Компиляция | amxxpc.exe (на Windows) или amxxpc (Linux) |
