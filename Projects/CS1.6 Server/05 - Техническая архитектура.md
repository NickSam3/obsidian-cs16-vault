# Техническая архитектура (4 Orange Pi)

## Распределение ролей

| Устройство | Роль | Нагрузка | Слоты |
|------------|------|----------|-------|
| **OPi #1** | Основной игровой сервер (ReHLDS) | Высокая | 16–20 (штурмы) |
| **OPi #2** | Второй игровой сервер (ReHLDS) | Средняя | 10–12 (скирмиши) |
| **OPi #3** | Стратегический сервер + API | Средняя | — |
| **OPi #4** | Веб-сервер + БД + FastDL + Telegram-бот | Низкая | — |

---

## Сетевая схема

```
(Интернет) → Роутер (порты 27015→OPi#1, 27016→OPi#2)
        ↓
OPi #1 (Игровой 1) ←→ OPi #3 (API) ←→ OPi #2 (Игровой 2)
                             ↑
                        OPi #4 (Веб + БД + Бот)
```

## Стек технологий

| Компонент | Технология |
|-----------|-----------|
| ОС | Armbian / DietPi |
| Контейнеризация | Docker + Docker Compose |
| Игровой движок | ReHLDS + ReGameDLL_CS (ARM) |
| Платформа плагинов | Metamod-R + AMX Mod X |
| База данных | MySQL (MariaDB) |
| Веб-сервер | Nginx |
| Backend API | Python (Flask) / Node.js (Express) |
| Telegram-бот | Python (aiogram) + Stars Payments |
